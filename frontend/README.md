# Workout Buddy (MERN CRUD + Context)

A full-stack MERN workout tracker using MongoDB Atlas, Express.js, React (`Context` + `useReducer`), and Node.js.

## Folder Structure
- `/backend` – Express REST API + Mongoose `Workout` model (`routes/`, `controllers/`, `models/`)
- `/frontend` – React + Vite frontend with global `WorkoutsContext` state management
